# Prototype v5: The Valley Unfolds

A frozen, playable copy. Open `play.html` in a browser.

One crew that works only where you give orders (plans, Clear and Fell), camps that double nearby work, five chapters
with a glowing goal hex, fix-it buttons for every blocker, and progress bars with ETAs.

Frozen when version 6 dropped workers altogether for a place-and-transform puzzle: play showed that ordering a crew
and then waiting on timers was not fun, because you never touched the valley yourself.
